# Engenharia de Prompt — Primeiro Emprego

Site interativo desenvolvido para uma atividade acadêmica sobre Engenharia de Prompt.

O tema escolhido foi **Orientação profissional para quem busca o primeiro emprego**.

## Objetivo

Comparar quatro estruturas de prompt aplicadas ao mesmo tema:

* PTF — Profissional, Tarefa e Formato
* CTF — Contexto, Tarefa e Formato
* CPTF — Contexto, Profissional, Tarefa e Formato
* EPTF — Exemplo, Profissional, Tarefa e Formato

A apresentação permite visualizar os prompts, consultar as respostas obtidas, comparar os resultados e analisar qual estrutura apresentou o melhor desempenho.

## Funcionalidades

* Navegação por seções
* Visualização dos quatro prompts
* Visualização individual das respostas
* Comparação entre PTF, CTF, CPTF e EPTF
* Análise da estrutura mais adequada
* Apresentação da melhoria do prompt com menor desempenho
* Botões interativos para as perguntas finais da atividade
* Navegação pelas setas do teclado
* Modo tela cheia
* Layout responsivo para computador e celular

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

O projeto foi desenvolvido em um único arquivo HTML, sem necessidade de bibliotecas ou frameworks externos.

## Como executar

1. Baixe o arquivo do projeto.
2. Renomeie o arquivo para `index.html`, caso necessário.
3. Abra o arquivo em qualquer navegador moderno.

Também é possível publicar o projeto utilizando o GitHub Pages.

## Estrutura da apresentação

1. Início
2. Prompts
3. Respostas
4. Comparação
5. Melhor estrutura
6. Melhoria do PTF
7. Conclusões

## Tema

Orientação profissional para quem busca o primeiro emprego.

## Resultado da análise

Entre as estruturas testadas, a CPTF apresentou o resultado mais adequado para o tema proposto, pois combinou contexto, papel profissional, tarefa e formato.

A comparação também mostrou que cada estrutura influencia a resposta de maneira diferente, principalmente em relação ao nível de direcionamento, organização e detalhamento.
